Notes
- Colours: Forest #244322, Sage #9BA77D, Lavender #86809C (linear gradient in that order). Usage ratio: 60% white, 15% Forest, 15% Sage, 10% Lavender.
- Typefaces: Playfair Display (titles, or Georgia) and Fabio XM (body). The website uses Figtree in place of Fabio XM until licensed web fonts are supplied.
- All text in the logo SVGs is converted to outlines. No fonts are required to use them.
