# Guided tour timed run (P5)

Manual run for the controller (sprint plan §6, D-20): follow the tour from step 1 to 16 with a
clock on the preview or production URL at the server default speed (4×; the Demo speed line on
`/demo/tour` must read "(server default)"). Reset the demo first with "Reset demo data". Log the
result in `PROGRESS.md` under "Guided tour timed run (P5)".

Target: 12 to 15 minutes in total (the script plans 14.25), no dead end. A stall is any moment the
next action was unclear, blocked or took longer than the step's planned minutes.
