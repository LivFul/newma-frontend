# P3 Frontend — Must Workflows W1–W6 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the frontend half of D-11 (W1 rights and policy view), D-12 (W2 evidence browser and curation queue), D-13 (W3 scripted-agent conversation with live jobs), D-14 (W4 gate tracker with step-up signed decisions and evidence diff), D-16 (W6 provenance timeline, manifest viewer, verify and tamper toggle, with a canonicaliser that matches the backend byte-for-byte) and D-15 (W5 closed wet-lab loop), each with BFF routes, pages, components, one happy and one failure Playwright path tagged `@needs-backend`, and an axe scan.

**Architecture:** As P2: the browser only talks to `src/app/api/demo/**` route handlers, which call the backend with `demoFetch`/`demoApi` (server-only), forward status, `Idempotent-Replayed` and the error envelope, and pass `details` only for codes in `DETAILS_ALLOWLIST`. Pages under `src/app/(platform)/demo/w1-rights … w6-provenance` are server components that read through the same helpers; interactive parts are small client components that call the BFF and `router.refresh()`. Shared demo components live in `src/app/(platform)/demo/_components/`; generic presentational pieces with no demo knowledge (evidence-label badge, synthetic badge, diff view, JSON viewer) live in `src/components/ui/` or `src/components/evidence/`. The canonicaliser is product code in `src/lib/provenance/canonical.ts` (no demo imports). The UI never decides authorisation: persona gating in the UI only hides/disables controls for convenience; the backend's 403 `persona_forbidden` is the authority and is rendered.

**Tech Stack:** as P2 (Next.js 16.3, React 19.2, Tailwind 4, Radix primitives, `openapi-fetch`, Vitest 5, Playwright + `@axe-core/playwright`). No new runtime dependencies; SHA-256 via `crypto.subtle.digest`.

**Spec:** D1 prompt phase card P3; sprint plan §3.2 rows W1–W6, §4.4, §5 rows D-11..D-16, §9 steps 2–6; prompt §3.1 labels, §3.2 synthetic rules, §3.6 budgets; TA §2–§4; PRD §3.2 (evidence distinctions), §3.3, §3.4, ENT-05; RM §1.3, §1.5, §2.6; ARCH §2D–§2F, §3; IP C-03, C-04.

## Contract (shared with the frontend/backend P3 plan — identical in both files)

All `/v1/*` requests: `Authorization: Bearer <BFF_SERVICE_TOKEN>` and `X-Demo-Session: <session_id>`. Error envelope `{code, message, details}`. Every route below is tenant-scoped (`tenant_scope`) and persona-checked with `require_persona(...)`; a persona outside the allowed set gets **403 `persona_forbidden`** with `details: {persona, allowed: string[]}`. "any" means all eight personas. Lists use `{items: T[]}`; paginated lists use `{items: T[], next_cursor: string | null}` with `?cursor=&limit=` (`limit` 1–100, default 25; bad cursor → 422 `invalid_cursor`). Writes marked (idem) take `idempotency_key` (`^[A-Za-z0-9._:-]{1,128}$`); a replay returns **200** with the original body and header `Idempotent-Replayed: true`; same key with a different body → 409 `idempotency_conflict`. Writes marked (event) append a signed provenance event and return its `event_id`.

Shared vocabularies (exact):
- `EvidenceLabel` = `literature_reported tentative_annotation computational_prediction measured_observation scientist_accepted unresolved_conflicting` (PRD §3.2). UI text: "Literature-reported", "Tentative annotation", "Computational prediction", "Measured observation", "Scientist-accepted", "Unresolved / conflicting".
- `ConstituentRelationship` (compound `identity_status`, PRD §3.5) = `reported_in_taxon detected_in_sample tentatively_annotated isolated_structure_confirmed`.
- `Purpose` = `research commercial disclosure model_training onward_transfer` (PRD ABS-03). `PolicyAction` = `ingest retrieve compute lab_transfer export train commercialise` (ARCH §3 Nagoya/CBD). `Decision` = `allow hold deny`.
- `GateStage` = `H0 H1 H2 H3 L1 L2 D`; `GateStatus` = `NOT_STARTED PENDING PASS FAIL HOLD INVALIDATED`; `LoopState` = the TA §3 snake_case states from P2 `lab/state_machine.py`; `JobKind` adds `eln_execution` to `screening admet`.
- `EntityType` (provenance) = `rights_record policy_decision claim curated_release agent_query gate work_package assay_import`.
- Signature label on every signed object: `"Demo signature, not production key"`.
