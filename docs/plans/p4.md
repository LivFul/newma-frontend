## Design direction

**Subject and job.** NEWMA joins ethnobotanical knowledge to computational prioritisation and laboratory evidence. The homepage must let a biopharma evaluator, a scientist and a community-governance reader understand in one screen what the platform connects, what it refuses to claim, and where to try it. Mode: Persuade, but credibility is carried by restraint and traceable sources, not by superlatives.

**Visual language: herbarium plate meets instrument schematic.** The dark-first night-indigo ground (`--color-bg`) is the plate table; content sits on it like specimen cards under a lamp. Headings use a system serif (new token `--font-display`, a `ui-serif` stack, zero font bytes) in the voice of a herbarium label; body stays on the existing sans stack; the mono stack appears only on literal identifiers (citation chips such as `TA § 4`). Display size comes from one new fluid token (`--text-display`, clamp between `--text-4xl` and about 4.5 rem) with tight tracking; every other size uses the existing `--text-*` scale. Spacing uses `--space-*`; sections breathe at `--space-16` desktop, `--space-12` mobile. Surfaces are flat `--color-bg-elevated` with `--color-border` hairlines only where they separate content groups (the six-component index, the persona grid); no identical-card walls, no gradient washes, no glow, no all-caps tracked eyebrow labels, no "01 / 02 / 03" except the four-step "how it works" row, which is a true sequence.

**The one memorable thing is the hero graphic**, so everything else stays quiet. Composition (viewBox portrait, about 480 × 640 user units, so labels stay at least 12 px rendered on a 360 px phone): six flat plates, drawn as slim rhombus slabs in a 2.5D axonometric stack, ordered top to bottom in the same order as the DOM and Tab order: Interface, Agentic Compute, Scientific Review, Wet Lab, Data & Knowledge, Provenance & DLT. **Assembled** state: the slabs sit as a tight stack with a short leader tick and the component name beside each. **Exploded** state: slabs separate along the vertical axis and drift slightly outward on alternating sides; a one-line descriptor fades in under each label; thin connection lines show the TA §1 flow: Interface → Agentic Compute → Scientific Review, Agentic Compute → Wet Lab (via the adapter) and Wet Lab → Scientific Review (results return for review), a left-hand rail linking every plate to Data & Knowledge (authoritative records), and a **dashed** line from Data & Knowledge down to Provenance & DLT (signed-log baseline first; ledger and anchoring optional). The dashed outline of the Provenance plate is the visual statement "optional".

**Glyphs** (abstract botanical-geometric, distinct silhouettes, never colour-only): Interface = a rounded frame bisected by one midrib line; Agentic Compute = a phyllotaxis spiral of seven dots; Scientific Review = a ring with a gate-notch crossed by a vein; Wet Lab = a teardrop paired with a small circle; Data & Knowledge = three stacked vesica (leaf-lens) shapes; Provenance & DLT = two interlocked rings, one dashed. No plants, species, people, communities or photography. A visible caption says: "Illustrative diagram. Glyphs are abstract and do not depict real species or deployed systems."

**Colour semantics (extend, do not fork).** Component hues follow the TA §1 class colours already used in the architecture diagram: Interface = `--color-accent` (sky), Wet Lab = `--color-success` (science green), Scientific Review = `--color-warning` (governance amber), Data & Knowledge = `--color-border-strong` strokes with `--color-fg-muted` ink (storage slate), Agentic Compute = new `--color-eco-compute` (violet), Provenance & DLT = new `--color-eco-optional` (coral, always paired with a dashed stroke). Both new tokens live in a new `src/styles/tokens/ecosystem.css`, are added to `contrast-pairs.json` (3:1 for strokes, 4.5:1 wherever used as text) and are verified by the existing `tests/unit/tokens.test.ts`. Hue is never the only carrier: glyph shape, label text and stroke pattern carry the same meaning. `--color-focus` stays the focus ring everywhere, including inside the SVG.

**Motion.** One orchestrated moment, answering a person's action: the explode (about `--motion-duration-slow`, `--motion-ease-emphasized`, stagger 0.06 s between plates, within the 0.05–0.10 s rule), and the reverse. No scroll reveals, no entrance fades on sections, no hover transitions on cards. Everything animates `transform` and `opacity` only; durations and easings are read from the motion tokens (`getComputedStyle` of the `--motion-*` variables once, falling back to constants mirrored in a test), never inline literals. `prefers-reduced-motion: reduce` yields the exploded labelled diagram with no transition and no animation, via CSS alone.

**Header.** Text wordmark "LivFul / NEWMA" left (assumption A-P4-01), two in-page anchors (Product, About LivFul) from `md` upward, and **Access NEWMA** top-right at every breakpoint as a `Button` (primary, minimum height 44 px). Sticky, solid `--color-bg` with a `--color-border` bottom hairline (no backdrop blur: it costs paint time and adds nothing).

**Page rhythm (desktop):** hero (text column left: h1, lede, "See the demo" primary, "How it works" link, disclaimer; graphic column right) → product introduction (what, the problem, four-step flow, guardrail, four personas) → components index (six links, the text twin of the graphic) → About LivFul (mission, vision, approach) → footer. Mobile stacks the hero text above the graphic. Copy is plain, active, sentence case; it describes design intent ("is designed to", "proposed") because the sources say deployment and performance are unverified.

## Review Focus

1. **Hero hydration cost, swap and CLS.** The static SVG and its interactive twin must be geometrically identical (same component, same viewBox, reserved aspect ratio, caption row with a fixed 44 px minimum height holding either the hint text or the toggle) so the swap produces zero layout shift (Playwright reads `layout-shift` entries across the swap). The swap happens in one commit (layout effect), keeps keyboard focus on the same slug, and is not triggered under reduced motion. Check the loader's idle/intent triggers, that Motion code is absent from first-load chunks (bundle script) and that LCP is the h1 or the static SVG, never a JS-rendered node.
2. **Touch model versus zoom and ghost clicks.** First tap explodes and must call `preventDefault` on the tapped link's click only while assembled and the pointer type is touch; the second tap opens; a tap outside collapses. Links use `touch-action: manipulation` (no double-tap-zoom delay) while pinch zoom stays available, the viewport never sets `maximum-scale` or `user-scalable=no` (asserted), the toggle is 44 × 44 minimum, and hybrid devices (touch plus mouse) classify by the event's `pointerType`, not by a device guess.
3. **Sticky header versus skip link, anchors and focus.** The skip link stays the first Tab stop and above the header (z-index), `html` carries `scroll-padding-top` and `#main`, `#product`, `#about` carry `scroll-margin-top` equal to `--size-header` plus spacing, so focused elements and anchor targets are never hidden behind the header (WCAG 2.4.11). Verify at 320 px width (wordmark plus button fit with no horizontal scroll), at 400% zoom, and that Access NEWMA remains clickable (hit-test, not only visible) at every scroll position.
4. **Claim drift.** Any sentence not in the claim register, any digit, percent, currency symbol, real-organisation name, LV-series id, unknown capitalised proper noun, or capability worded as fact rather than design intent ("is designed to", "proposed") must fail `pnpm check`. Review the About LivFul draft and the six pages against the quoted source sentences in the content matrix, and the public citation of internal documents (A-P4-09). The DLT page must say optional and off-chain in prose, and the hero and index labels must not imply a deployed ledger.
5. **URLs behind Vercel preview hosts.** On a preview, canonical, `og:url`, `og:image`, sitemap entries and JSON-LD `url` must still be the canonical production origin (A-P4-10), robots must disallow everything off-production, and OG images must be fetchable on the canonical origin once deployed (check by fetching `/opengraph-image` on the preview and the absolute URL in the meta tag on production). `NEXT_PUBLIC_*` values are inlined at build: confirm the build-time value, not a runtime header, drives metadata.

### Task 2: Hero interaction model, lazy hydration, reduced motion, no-JS (D-04 part 2)

**Files:** `src/components/ecosystem-graphic/{state.ts,hero-loader.tsx,interactive.tsx,motion-part.tsx,motion-features.ts,keyboard-help.tsx,hero-marker.ts}`, `src/components/ecosystem-graphic/ecosystem-graphic.tsx` (compose), `tests/unit/ecosystem/{state,hero-loader,interactive}.test.tsx`, `tests/e2e/hero-model.spec.ts`, `tests/e2e/hero-nojs.spec.ts`, `tests/e2e/hero-reduced-motion.spec.ts`, `tests/a11y/hero.spec.ts`.

**Interfaces:**

- `state.ts` (pure reducer, the whole interaction model): `HeroState = {view:"assembled"|"exploded"; pinned:boolean; suppressed:boolean; active: EcosystemSlug | null}`; events `pointerEnter | pointerLeave | focusIn(slug) | focusOut | arrow(dir) | home | end | escape | toggle | tap(slug|null, touch:boolean, view) | outsideTap`. Rules: mouse enter/leave and focus-in/out explode and collapse unless `pinned`; `toggle` pins/unpins; `escape` collapses, unpins and sets `suppressed` until focus leaves or the pointer leaves; an arrow or Tab-driven focus-in after `escape` clears `suppressed`; `arrow` right/down = next, left/up = previous, `home`/`end`; no wrap; arrows `preventDefault` only when focus is inside the graphic and the layer is interactive. Touch: `tap` while assembled returns `{explode, preventNavigation: true}`, `tap` on a slug while exploded returns `{navigate}`; `outsideTap` collapses an unpinned touch-opened view.
- `hero-loader.tsx` (`"use client"`): `const Interactive = dynamic(() => import("./interactive"), { ssr: false, loading: () => null })` (the Next docs require `ssr: false` inside a client component). Props `{ children: ReactNode }` (the server-rendered static figure). Loads Interactive when: not `matchMedia("(prefers-reduced-motion: reduce)")`, and one of `requestIdleCallback` (timeout 2000 ms, `setTimeout` fallback), first `pointerenter`/`focusin`/`touchstart` on the container.
