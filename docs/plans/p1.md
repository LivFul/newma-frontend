# P1 Frontend — Remote and Deploy Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `newma-frontend` CI-complete on GitHub (LivFul/newma-frontend) and Vercel (project `newma-frontend`, scope `danlivfuls-projects`): unit checks on every PR, Playwright + axe + Lighthouse CI against each Vercel preview via `deployment_status`, Sentry SDK wired behind `NEXT_PUBLIC_SENTRY_DSN`, and the contract check able to fetch the spec from the deployed API.

**Architecture:** Vercel builds previews per PR and production on `main` (Git integration or CLI deploy from CI; the controller decides which after the Vercel plan question is answered — the workflows below work for both because they key off `deployment_status`). A `deployment_status` workflow waits for the preview to succeed, then runs the E2E and a11y suites against it with the Vercel protection-bypass header. `api/openapi.lock` keeps a relative `source` for local dev; CI overrides the source with `API_CHECK_SPEC_SOURCE` pointing at the Railway `demo` API's `/openapi.yaml`.

**Tech Stack:** GitHub Actions, pnpm 12, Playwright 1.63, @axe-core/playwright, @lhci/cli, @sentry/nextjs 11, gitleaks action, Renovate, amannn/action-semantic-pull-request.

**Spec:** D1 prompt phase card P1; sprint plan §4.2–4.3; IP §5.3–5.6; pitfall register 7, 11, 12.

## Global Constraints

- Names only in `.env.example`; never commit `.env.local` or `.vercel/`.
- No `NEXT_PUBLIC_DEMO_MODE` outside demo dirs (guard stays green).
- Budgets wired: Lighthouse Performance ≥90, Accessibility 100, SEO ≥95; LCP ≤2.5 s; CLS ≤0.1.
- `src/lib/api/generated/` never hand-edited; `pnpm api:check` must pass in CI with the remote source.
- Files < 800 lines, functions < 50 lines; TDD for any `src/` or `scripts/` change; conventional commits.

## Review Focus

1. **Protected previews** — Vercel Authentication blocks Playwright unless the `x-vercel-protection-bypass` header is sent on every request (set via `extraHTTPHeaders`).
2. **Deployment-status noise** — the workflow must run only for `state == success` and `environment == Preview`, never for Production.
3. **Sentry without DSN** — build and runtime must be clean when `NEXT_PUBLIC_SENTRY_DSN` is empty; `withSentryConfig` must not require `SENTRY_AUTH_TOKEN`.
4. **Spec source override** — `API_CHECK_SPEC_SOURCE` must not loosen the sha check: the pinned sha must still match the fetched remote spec.
5. **Lighthouse on previews** — `LHCI_URL` must carry the bypass as query parameters (`?x-vercel-protection-bypass=…&x-vercel-set-bypass-cookie=true`) because Lighthouse cannot set headers, and `lighthouserc.cjs` must not start a local server when `LHCI_URL` is set.

// src/lib/observability/sentry-options.ts
export type SentryEnv = { NEXT_PUBLIC_SENTRY_DSN?: string; VERCEL_ENV?: string };
export function sentryOptions(env: SentryEnv) {
  const dsn = env.NEXT_PUBLIC_SENTRY_DSN?.trim() || undefined;
  return {
    dsn,
    enabled: Boolean(dsn),
    environment: env.VERCEL_ENV ?? "development",
    tracesSampleRate: 0.1,
    sendDefaultPii: false,
  } as const;
}

`preview-e2e.yml`:

```yaml
name: Preview E2E
on:
  deployment_status:
jobs:
  e2e:
    if: github.event.deployment_status.state == 'success' && github.event.deployment_status.environment == 'Preview'
    runs-on: ubuntu-latest
    env:
      PLAYWRIGHT_BASE_URL: ${{ github.event.deployment_status.environment_url }}
      VERCEL_AUTOMATION_BYPASS_SECRET: ${{ secrets.VERCEL_AUTOMATION_BYPASS_SECRET }}
    steps:
      - uses: actions/checkout@v4
        with:
          ref: ${{ github.event.deployment.sha }}
      - uses: pnpm/action-setup@v4
        with:
          version: 12
      - uses: actions/setup-node@v4
        with:
          node-version: 26
          cache: pnpm
      - run: pnpm install --frozen-lockfile
      - run: pnpm exec playwright install --with-deps chromium
      - run: pnpm test:e2e
      - run: pnpm test:a11y
      - name: Lighthouse CI
        env:
          LHCI_URL: ${{ github.event.deployment_status.environment_url }}/?x-vercel-protection-bypass=${{ secrets.VERCEL_AUTOMATION_BYPASS_SECRET }}&x-vercel-set-bypass-cookie=true
        run: pnpm exec lhci autorun
      - uses: actions/upload-artifact@v4
        if: always()
        with:
          name: playwright-report
          path: playwright-report
          retention-days: 7
```
